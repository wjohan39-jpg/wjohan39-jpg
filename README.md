## Proyectos destacados

### Públicos

- **[Diossy Capilar](https://github.com/wjohan39-jpg/DiossyCapilar)** — Sitio web de una marca colombiana de productos capilares naturales: catálogo, galería multimedia, contacto por WhatsApp y política de privacidad. HTML, CSS y JavaScript, publicado en Netlify.
- **[Diossy Capilar Backend](https://github.com/wjohan39-jpg/DiossyCapilar-Backend)** — Capa de datos del negocio con Spring Boot 3, JPA y SQL Server, más una consola de gestión. La API REST está en desarrollo.

### Privados (puedo mostrarlos en una conversación)

- **Aqua Tech** — Aplicación web progresiva (PWA) para la gestión de la calidad del agua en piscinas según la Resolución 234/2026 de Colombia: bitácora sanitaria, calculadora de dosificación química, índices IRAPI y de Langelier, y reportes en PDF. Funciona sin conexión.
- **Automatización de liquidación (Python, fases 1 y 2)** — Detecta conductores con soportes pendientes, los contacta por WhatsApp Cloud API, recibe la foto del comprobante, la convierte a PDF y se la entrega al analista asignado. Piloto probado con datos reales.
- **Automatización con n8n** — Flujo que recibe datos por webhook, genera una colilla de pago en PDF y la envía por WhatsApp, con validación de datos y modo de prueba.
